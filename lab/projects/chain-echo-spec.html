이 페이지는 명세서 v0.1 의 구조를 살려 요약한 것입니다. 상태 표기는 원문을 그대로 따릅니다 — [확정] 사용자와 대화에서 채택한 규칙 · [잠정] 제안됐으나 수치·방식 검증 전 · [미결정] 방안이 여럿이거나 확정 없음. 몬길: 스타다이브 캐릭터 콘셉트를 차용한 IP 활용 게임이며 비영리 창작 게임입니다. 원작 게임의 그림과 소리는 넣지 않았습니다.

포트폴리오 목적 [확정] — 목표 A: 독창적인 핵심 재미 시스템의 실제 구현(타이밍을 맞춘 태그의 명확한 추가 보상, 이전·다음 캐릭터 행동의 자연스러운 연결, 동일한 고유 기술의 이동·전투 겸용). 목표 B: 튜토리얼형 스테이지의 자연스러운 학습 흐름을 통한 레벨 디자인 역량 입증.

핵심 규칙

태그 — 교체가 아니라 연계 [확정]

태그 버튼 입력 한 번으로 캐릭터가 교체되고 다음 캐릭터의 고유 기술이 자동 발동한다. NORMAL 태그에서도 자동 발동한다. 태그는 전투와 이동에 동일한 기본 시스템을 사용한다.

  • 캐릭터별 고유 기술 — 빨강(플레아) 용 변신 화염 돌진 [핵심 컨셉 확정], 파랑(오필리아) 빙결 활주 [A안 확정], 바람(클로에) 상승 기류 [핵심 컨셉 확정]. 수치와 적중 효과는 대부분 [잠정].
  • 태그 자원은 2회 충전형 스택(최대 2, 2초마다 1개 회복) [잠정]. 교체 순서(고정 vs 자유 선택)·등장 위치·입력 방향은 [미결정].

PERFECT — 적중 직후의 태그 [확정 / 시간 잠정]

공격이 실제 적에게 적중한 직후 태그하면 PERFECT. 교체되어 나가는 캐릭터가 공격의 남은 동작을 에코로 마무리하고, 사용한 태그 스택 1개가 반환된다. 허공 공격이나 순수 이동에는 PERFECT 가 없고, 놓치면 NORMAL 태그로 작동하며 벌칙은 없다.

  • 타이밍 윈도우 250ms 는 추천 초기 테스트값 [잠정]. 기술 1회당 PERFECT 기회 1회 [잠정].
  • 일반 공격으로 PERFECT 가능 여부, 에코의 타격 횟수·범위·대미지는 [미결정].

연계 게이지와 3인 합동 필살기 [확정된 방향]

캐릭터별이 아닌 파티 전체 공용 게이지 1개. 전투 태그/공격 적중으로 충전하며 PERFECT 에 더 큰 보상. 게이지 100% 에서 3인 합동 필살기. 허공 태그만 반복해 충전하는 구조는 지양.

  • 연출 순서 — 빨강 용 화염 돌진 → 파랑 빙결 연계 → 바람 상승 기류 후속 → 세 캐릭터 합동 마무리 [잠정]. 충전량·필살기 대미지·사용 조건은 [미결정].

스테이지 구성 — 학습 기반 레벨 디자인

[확정] 총 5개 스테이지, Stage 5는 최종 보스전. 전체 5~10분. 시스템을 하나씩 추가하는 구조가 아니라 같은 핵심 기술을 여러 맥락에서 활용해 배우는 구조이며, 지나친 설명 텍스트 없이 지형과 적의 배치로 행동을 유도한다. Stage 2에 PERFECT 학습을 배치한다.

Stage역할학습·검증 요소초기 시간 배분 [잠정]
1-1발견 — 태그 이동이동·점프·태그 시 기술 자동 발동45~60초
1-2학습 — 태그 전투공격 적중 후 PERFECT, 에코 공격60~90초
1-3응용 — 연속 태그태그 스택, 세 캐릭터 이동·전투 연계60~75초
1-4숙달 — 복합 상황이동과 전투를 결합, 연계 게이지와 3인 필살기75~105초
1-5최종 검증 — 보스이동 회피, PERFECT 연계, 에코, 게이지 활용90~150초

최종 보스 [핵심 구조 확정 / 패턴 잠정] — 새 기술 학습보다 기존 학습의 검증에 집중한다. 지면 충격파(수직 이동), 전방 돌진(태그 이동 회피), 공격 후 빈틈(PERFECT 태그), 무방비 구간(3인 연속 기술), 체력 후반부(합동 필살기)가 패턴 후보이며 상세 AI·체력·간격은 [미결정].

피할 것 — PERFECT 실패 시 이동 불가한 길, 설명문 없이는 이해 못 하는 구간, 스테이지마다 새 조작을 계속 추가하는 설계, 스택 회복만 기다려야 하는 발판, Stage 5에서 처음 등장하는 필수 시스템.

구현 전에 확정해야 할 미결정 항목

명세서 §11 의 항목 제목만 옮깁니다. 높은 우선순위 8개 · 중간 우선순위 7개.

  1. 태그 선택 방법: 고정 순서인가, 자유 선택인가
  2. 기술 직접 사용 버튼의 존재 여부와 쿨타임 관계
  3. 방향 결정: 파랑 빙결 활주 4방향 vs 8방향
  4. 새 캐릭터의 출현 위치·속도 계승
  5. 태그 스택 최종 채택(최대 2 · 회복 2초 · PERFECT 1개 반환)
  6. PERFECT 판정 공격 범위(기본 공격 허용 여부, 다단히트)
  7. 빨강 돌진 방어 정책(경직 면역·접촉 공격·보스 예외)
  8. 파랑 경로 충돌 구현(경사 단방향 발판·1.5초 소멸)
  9. 바람 상승 기술의 공격 판정 및 추가 효과
  10. 에코 공격의 정확한 프레임/시간/대미지
  11. 게이지 충전량·조건, 필살기 대미지 및 사용 조건
  12. 캐릭터별 능력 수치, 물리·스프라이트 크기, 판정 시간
  13. 스테이지별 구체 맵, 체크포인트·리스폰·게임오버
  14. 적/보스 아트, AI 상태·경직 저항 정책
  15. Phaser 웹 개발 환경 최종 선택 여부

한 문장 게임 정의

세 캐릭터의 이동·전투 기술을 태그로 연결하고, 공격 적중 직후의 PERFECT 태그로 에코 공격과 연속 연계 보상을 얻으며, 다섯 개의 점진적 학습 스테이지를 거쳐 최종 보스를 공략하는 2D 도트 액션 플랫포머.
